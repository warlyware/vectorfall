# VECTORFALL project instructions

## Versioning

- `package.json` is the authoritative application version. The title screen reads it directly; do not duplicate the version in source code.
- For each subsequent task that changes application code, assets, configuration, or user-facing behavior, increment the semantic patch version in both `package.json` and the root entry of `package-lock.json` (for example, `1.0.0` to `1.0.1`).
- Do not increment the version for read-only investigation or discussion that makes no repository changes.
